# Smileline plugins

Plugins that connect AI tools to [Smileline](https://smileline.io), the dental
practice CRM.

## Claude Code

```bash
claude plugin install smileline --marketplace smilelinecms/smileline-plugins
```

Then run `/mcp` in Claude Code and sign in to `smileline`. Sign-in asks
whether your practice's account is in Europe or the United States.

See [`plugins/smileline`](plugins/smileline/README.md) for what the plugin
contains, what it can do, and where your data goes.
